# Бизнес-процесс заявки

1. Сотрудник регистрируется → подтверждает email → администратор активирует (`status: active`).
2. Сотрудник создаёт заявку (`new`) → диспетчер получает уведомление.
3. Диспетчер назначает исполнителя (`assigned`) → исполнитель принимает (`in_progress`).
4. Исполнитель завершает (`completed`) → заявитель или диспетчер закрывает (`closed`).
5. Все шаги пишутся в `requestEvents`.

Отказ исполнителя возвращает заявку в `under_review`.
